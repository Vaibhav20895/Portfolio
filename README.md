# Vaibhav Bhardwaj — Portfolio

Personal portfolio site. Single static HTML file, no build step, no framework.

## Files

- `index.html` — the entire website (HTML, CSS, JavaScript and the particle
  artwork data are all inside this one file)
- `netlify.toml` — tells Netlify to serve this folder as-is
- `.gitignore` — keeps OS and editor junk out of the repository

## Hosting

Deployed on Netlify from the `main` branch of this repository.
There is no build command and no publish directory to configure — pushing a
change to `main` republishes the site automatically.

## Editing

Change `index.html`, commit, and push. Netlify redeploys within about a minute.
